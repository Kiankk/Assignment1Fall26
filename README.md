# Typing Tutor

Assignment 01 — Program Development in a Graphical Environment

A JavaFX desktop application that helps a user practise touch typing. The
program shows a line of sample text, echoes what the user types, highlights the
matching key on an on-screen keyboard, and reports typing accuracy.

## Status

Work in progress.

## Build and run

```
mvn clean javafx:run
```
